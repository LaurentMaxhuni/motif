Privacy & data

Your work stays where you made it.

Motif is software you run, not a service you sign up for. There's no Motif account, no Motif cloud, and no telemetry. This page explains exactly what stays on your computer and what reaches the network, and when.

What stays local

Everything you create is stored in data/motif.sqlite in the Motif folder. That includes your brands and Brand DNA, product photos, creations and their version history, research reports you've applied, the calendar and settings.

Website analyses run inside the local server. They're temporary jobs, so nothing is stored until you review and apply the result. Restarting the server ends pending jobs and clears generation progress.

The interface is locked down with a Content Security Policy, so the browser can only talk to your local Motif server.

What uses the network

The network is used only for the actions below, and only when you start them.

When you…What's contactedWhat's sent
Analyze a websiteThat site's public pages, robots.txt, sitemap and up to three stylesheetsOrdinary page requests. Motif never logs in, runs the site's scripts, or downloads its images or fonts.
Use a local modelThe loopback address you enteredPrompts with your brand context, sent only to your own machine
Use a coding CLIWhatever cloud model that CLI is configured forPrompts, brand context, website excerpts and requested copy
Use Cloudflare imagesCloudflare Workers AIThe artwork prompt
Test or send to Buffer, Metricool or ZernioThat provider's official APIYour credentials and, when sending, the caption, media and schedule you reviewed

A note on local servers: Motif accepts only loopback addresses for model endpoints and rejects redirects. But it can't control what a separate model server does, so make sure yours is set up to run locally.

Website analysis safeguards

  • Respects robots.txt and stays on the same origin.
  • Checks and pins DNS on every request, and refuses private destinations, unusual ports, oversized documents, disallowed paths and long redirect chains.
  • Has byte, request and time limits on every job.

Credentials

Connector and image-provider credentials are encrypted with AES-256-GCM and stored in a separate database table. The key lives in data/connector.key, next to your database.

  • Credentials, their ciphertext and the key are never included in JSON exports. Re-enter them on a new installation.
  • A physical copy of the database does contain encrypted secrets. Protect it and the key file with your normal account and disk security.
  • Don't delete the key file if you want existing connections to keep working.
  • Coding CLIs keep their own sign-in. Motif never copies CLI credentials into its database.

Exports & backups

Download workspace backup in Settings produces a consistent JSON copy of your brands and content while Motif is running. Importing a backup adds new copies and never overwrites existing data or endpoint settings. Connections and delivery history are left out of exports on purpose.

Deleting a creation also deletes its version history.

Rendering safety

AI-written HTML and CSS are checked against an allow-list of tags, attributes and CSS before rendering. Creatives are rendered in an isolated local browser with JavaScript disabled and every network request blocked. Images returned by a model must be embedded PNG, JPEG or WebP, and Motif never fetches remote image URLs.

About this website

This website is a set of static pages. It sets no cookies and loads no analytics, trackers, embeds or third-party fonts. Everything, fonts included, is served from the same place as the page. The only thing it stores is your light or dark theme choice, kept in your own browser's local storage.
