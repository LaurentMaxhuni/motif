Get started

Your studio, running in minutes.

Motif runs as a local web app. Install it once, start it whenever you want to work, and open it in your browser at 127.0.0.1.

Requirements

You needWhy
Node.js 22.13+Runs the local server, which uses Node's built-in SQLite and TypeScript support.
pnpmInstalls dependencies from the lockfile.
Chrome, Chromium or EdgeRenders finished creatives in an isolated local browser. Detected automatically on Windows, macOS and common Linux paths.
A text and image model (optional)Needed for AI generation. Offline templates work without one.

You need an internet connection to install dependencies. After that, Motif works offline with templates and any local models you run.

Install & run

  1. Get the code

    Clone the repository, or download it and unzip it somewhere you'll keep it.

    terminal
    $ git clone https://github.com/LaurentMaxhuni/motif.git
$ cd motif

  2. Install dependencies

    ~/motif
    $ pnpm install --frozen-lockfile

  3. Start Motif

    pnpm start type-checks and builds the interface, then starts the local server. On Windows you can double-click start-motif.cmd instead.

    ~/motif
    $ pnpm start

  4. Open your studio

    Go to http://127.0.0.1:3333. Keep the terminal open while you work, and press Ctrl+C to stop.

Your first brand

A fresh install opens on guided setup. You can start in one of two ways:

  • Analyze your website. Enter your site's address and choose how many pages to read. Motif drafts your Brand DNA with sources for every finding.
  • Enter it yourself. Write your brand's name, products, audience, voice and colours by hand.

Either way, you review the details before anything is saved. To add another business later, use Add brand.

Tip: if your site redirects between www and the bare domain, enter the final address. Sites that only render with JavaScript may need some details filled in by hand.

Connect a model

Open Settings → AI providers. Motif doesn't start a model or download weights, so start your model server first.

Coding CLI

Already use Claude Code, Codex, OpenCode, Pi or OMP? Install it and sign in from your terminal first. Then pick it as your Text AI provider, run Detect installed CLIs, then Test selected CLI, then save. These CLIs may send prompts to their own cloud service. See what uses the network.

Images

Choose Cloudflare Workers AI (FLUX.1 Schnell), Unsloth Studio, or any local OpenAI-compatible /images/generations URL. Image keys are stored encrypted.

Your first campaign

  1. Open Creative studio, pick a format, and write a short brief.
  2. Start with 1 variation. Larger batches generate artwork one at a time and can take several minutes.
  3. Open the result and describe any change, then click Revise with AI.
  4. Click Save creation, approve it, then download a PNG or put it on the calendar.

Updating

Pull the latest code, run pnpm install --frozen-lockfile again, then pnpm start. Keep the data folder: it holds your workspace database and the key that unlocks your saved credentials. Existing databases and backups load directly.

Troubleshooting

Port 3333 is already in use

Choose another port before starting. In PowerShell:

PowerShell
> $env:PORT=3334; pnpm start

On macOS or Linux, use PORT=3334 pnpm start.

Creatives won't render

Motif needs Chrome, Chromium or Edge. If yours is installed somewhere unusual, set CHROME_PATH to the browser's executable before starting.

A model returns an error

Motif shows the error rather than quietly using a template. Check that the model server is running, the model ID matches exactly, and that the model can return JSON. For CLIs, run Test selected CLI to check the sign-in.

“Dependencies missing” from the Windows launcher

Run pnpm install --frozen-lockfile in the Motif folder once, then double-click start-motif.cmd again.
