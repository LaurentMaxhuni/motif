# Local website Brand DNA analysis

`analyzeWebsite({url, maxPages:12, useAI:false}, settings, dependencies={})` returns an editable brand draft plus `analysis`. All extraction runs inside the local Node process. Optional synthesis uses the selected loopback server or CLI text provider. Website downloads contact the requested public website. CLI interpretation may send excerpts to a cloud model; extraction without interpretation stays in the local Node process. See [CLI providers](cli-providers.md).

The crawl reads robots.txt first, respects the most specific MotifLocal or wildcard group, and follows same-origin links and up to four sitemap files. Explicit 404/410 robots responses permit crawling; other robots failures stop analysis. Sitemap indexes expand to two levels within the four-file limit. Raw .xml.gz files are unsupported; HTTP gzip, deflate and Brotli responses are decoded with bounded streaming. About/company, products/services, pricing, FAQ and audience pages take priority. Login/account/cart/checkout/action paths, credentials, private IP literals, nonstandard ports and non-HTTP URLs are excluded. The shared transport resolves and checks every hostname and redirect, rejects private/special-use addresses, and pins the selected DNS address. A transport `allowUrl` callback checks robots permission before fetching each redirect target. Same-origin redirects only; enter the final canonical origin if the site redirects between www and non-www hosts. Page query strings and fragments are removed before crawling; sitemap and stylesheet query strings remain intact. Canonicals collapse pages only when the declared same-origin target was already analyzed.

Bounds: 1–20 successful pages (12 default), 36 actual HTTP requests including redirects, discovery and CSS, 75 seconds across crawling and optional synthesis, 12 MB aggregate transfer, 2 MB per response, 120,000 retained text characters and up to three same-origin stylesheets. The frontier holds at most 500 URLs. Requests are sequential. Failed pages and unavailable assets remain visible. The scan deadline also bounds uncooperative synthesis adapters. The HTML crawl executes no JavaScript and downloads no images, remote fonts, CSS imports or cross-origin resources; the optional browser scan below does, under its own budget.

`analysis` contains:

- `pages`: URL, title, description, headings, bounded excerpt, approximate word count, metadata, structured data, CTA and visual signals.
- `findings`: company wording, product/service candidates, explicit audience wording, positioning/benefit phrases, publisher proof claims, voice samples/interpretation, visual palette/font/logo references, per-page SEO issues, content and technical coverage.
- `evidence`: claims tagged `observed` or `inferred`, source URLs and supporting quotes where available.
- `warnings`: missing evidence, extraction limitations, partial failures, scan limits and synthesis fallback.
- `coverage`: request/byte/text counts, page counts, pending URLs, skips, failures, robots state, sitemap and limits.

Completed React streamed-HTML boundaries can be assembled from literal boundary references already in the response; scripts are never evaluated. Navigation, cookie/cart dialogs and hidden content are excluded from copy. Metadata-only pages and detected challenge/empty pages receive explicit coverage warnings. Localized copies and repeated about pages have lower crawl priority. Nested JSON-LD retains products, but a product manufacturer cannot become the website identity; explicit ProductGroup variants remain evidence while the summary uses their parent group. Duplicate candidates merge source URLs and stronger structured evidence upgrades earlier heading candidates.

Products inferred from headings are labeled candidates. Publisher copy and JSON-LD are observations, not independently verified facts. Palette selection prioritizes explicit brand/primary/accent declaration hints before frequency. These hints describe source declarations, not computed appearance or verified official brand hierarchy. Modern RGB/HSL/OKLCH and opaque alpha hex colors are normalized. Fallback colors are disclosed. Without a model, voice is the measured writing profile (see below) and audience uses explicit site wording only. Missing evidence stays visible rather than receiving generic persona claims.

Optional synthesis receives bounded excerpts across all analyzed pages. It may add only audience and voice interpretations with exact source URLs and verbatim supporting quotes. Structure, field lengths, provenance and quote presence are validated before applying any output. Invalid or unavailable synthesis retains the extraction result. Quote validation establishes attribution, not semantic truth; all model interpretations require review. Website text is explicitly untrusted model input.

Large reports compact excerpts, headings, schema and asset lists before local storage, with an explicit warning. Evidence and findings remain available.

For fixtures, inject `fetchDocument(url, redirects, options)` returning `{html,url}`, `infer(settings,messages,json,maxTokens,signal)` and/or `onProgress({stage,pages,pagesCompleted,maxPages,url?,currentUrl?})`. An optional `dependencies.signal` cancels network requests and is checked between crawl and synthesis steps. The signal aborts the local model HTTP request or terminates the CLI process tree; the upstream model server may continue processing internally. Cancellation stops awaiting synthesis even when a fixture adapter ignores the abort signal. Transport options include `allowedMime`, `sameOrigin`, `maxBytes`, `timeoutMs` and abort `signal`; HTTP errors expose `statusCode`. Tests use in-memory fixtures and never call public websites or a model.

## Browser scan (colors, fonts, logos, imagery)

With `render: true` (the app's default, a checkbox in the research dialog), Motif also loads up to three key pages (home, then about/product pages) in headless Chrome with the site's own JavaScript, and measures what visitors actually see:

- **Palette** (`findings.visualIdentity.brandPalette`): every painted color weighted by area, text size and role (buttons and links, logo, headlines, backgrounds, body text). Near-identical shades are merged. Brand colors are chosen by their share of each role, so the color on every button beats a large illustration tint, and a color the CSS names `--brand`/`--primary` still leads. Up to six colors are saved on the brand (primary, secondary, accents, text, background).
- **Typography**: computed families for headlines, body text and buttons, plus the web fonts that actually loaded.
- **Logos** (`logoImages`): header and home-link images or SVGs, captured as PNG with the background they sit on. Customer and review-site logo walls are filtered out.
- **Imagery** (`images`): the largest visible photos and background images, re-encoded at up to 960px so the report stays small. Any of them can be set as the brand's product photo.
- **Homepage screenshot** for reference, and the rendered HTML, which replaces thin or JavaScript-only pages in the copy analysis.

Chrome never touches the network itself: host resolution is disabled (`--host-resolver-rules=MAP * ~NOTFOUND`) and every request is fulfilled through the same public transport as the crawl, which pins DNS and rejects private and special-use addresses. Page navigations are limited to the same site and robots.txt; POST requests, iframes, media, websockets and common analytics or consent scripts are blocked. Budgets: 260 requests per page, 40 MB total, 70 seconds. Without Chrome, or if the scan fails, the HTML results are kept and a warning explains it. Set `CHROME_PATH` to use a specific browser.

## Figures and voice

`findings.figures` lists statistics, prices, ratings and founding dates quoted on the site (phone numbers, copyright years and rankings such as "Fortune 500" are ignored), each with its sentence and page. `findings.voice.style` measures the copy itself: sentence length, "you" versus "we", contractions, exclamation and question use, reading ease, headline casing, emoji and the words the brand uses most. Without an AI model, its summary becomes the brand voice. With AI interpretation, the model may add up to seven quoted, evidence-checked findings (`findings.brandDNA`): audience, voice, personality, values, positioning, tagline and mission. Image data is stripped before brand context reaches any model prompt.
